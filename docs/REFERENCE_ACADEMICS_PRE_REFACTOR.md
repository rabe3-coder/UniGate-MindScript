# Mind Script eng.rabe3 — إدارة الخطط الدراسية والعلامات

## التشغيل في Windows
1. ثبّت Python 3.10 أو أحدث.
2. فك الحزمة في مجلد جديد.
3. شغّل `START_WINDOWS.bat`، ثم افتح `http://127.0.0.1:8765`.
4. ادخل بحساب شؤون الطلاب `affairs` أو المدير `admin` (كلمة مرور بيانات التجربة: `Demo123!`).
5. افتح «شؤون الطلاب»، اختر طالبًا، ثم «فتح الملف». أسفل الملف ستجد «الخطة الدراسية والعلامات».
6. أضف المقررات الإلزامية للخطة ثم أدخل العلامات الرقمية. يعاد حساب المعدل والساعات المتبقية تلقائيًا بعد الحفظ.

## نقل التحديث إلى نسختك الحالية (بدون فقد الأسماء والتسجيلات)
1. **أوقف الخادم** وأغلق DB Browser for SQLite.
2. انسخ قاعدة `registration.sqlite3` القديمة احتياطيًا قبل أي تغيير.
3. خذ الملفات `server.py` و`static/app.js` من حزمة **Update Only**، واستبدل الملفين المناظرين فقط.
4. **لا تستبدل ولا تنسخ `registration.sqlite3`** إلى مشروعك القديم.
5. شغّل الموقع: يضيف `init_db()` جدولَي `student_plan` و`course_grades` دون مسح الجداول الموجودة.
6. اختبر بحساب شؤون الطلاب، وابدأ بإضافة خطة صغيرة لطالب تجريبي، ثم أدخل علامة.

## ماذا يُحسب؟
- درجات رقمية من 0 إلى 100، مع حد نجاح **افتراضي للتجربة**: 60.
- نقاط المعدل الأربع **للمحاكاة فقط**: 90–100 → 4.0، 80–89.99 → 3.0، 70–79.99 → 2.0، 60–69.99 → 1.0، أقل من 60 → 0.
- المتوسط موزون بساعات المقررات التي لديها درجات رقمية مسجلة فقط.
- مجموع الساعات المطلوب والمجتاز والمتبقي يُحسب لمقررات الخطة **الإلزامية المدخلة** فقط؛ المواد الاختيارية تُعرض دون حساب متطلب عدد اختياريات رسمي.
- النتائج القديمة في `completed` بلا علامة رقمية تُعرض كحالة تحتاج توثيقًا، **ولا تتحول إلى درجة أو معدل تخميني**.
- `all_plan_courses_passed` لا يعني منح الشهادة، و`potential_this_term` مجرد مؤشر على طرح مقررات الخطة المتبقية وساعاتها، دون التحقق من كامل الخطة الرسمية أو جميع القواعد والقيود. **التخرج الرسمي غير معتمد آليًا**.
- إدخال أو تعديل علامة رقمية يحدّث `completed.passed` مما ينعكس على أهلية المتطلبات السابقة. التسجيلات القديمة لا تُلغى تلقائيًا وتحتاج مراجعة إن تأثرت.
- كل تغيير يحتاج سببًا موثقًا، ويحفظ في `audit`؛ عمليات التعديل مقيدة بشؤون الطلاب والمدير.

## الحدود الحالية
هذه نسخة تعليمية محلية. لا توجد تكاملات تلقائية مع نظام علامات الجامعة أو الخطط الرسمية؛ سلم العلامات ليس ثابتًا رسميًا. لا يدعم حساب معدل إعادة المواد أو تحسين الدرجات أو الساعات المحولة أو الساعات الاختيارية المطلوبة بشروط أو برامج تخصص متعددة. قبل الاستخدام الواقعي يجب اعتماد لوائح الجامعة وحماية النظام واتصال آمن ومراجعة بشرية.

## الملفات المعدلة
- `server.py`: ترقية إضافية لقاعدة SQLite، ومسار `/api/affairs/academic`، والحسابات، وسجل التدقيق.
- `static/app.js`: إدارة الخطة والدرجات والنتائج من شاشة شؤون الطلاب.
- `test_academics.py`: اختبار تلقائي مستقل على قاعدة مؤقتة، لا يلمس `registration.sqlite3` الخاصة بك.
